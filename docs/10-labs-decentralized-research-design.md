# LABS 自证研究与有限世界资源结算设计

## 文档状态

本文定义 SAI 首个成果自证型研究协议及其与有限世界资源的结算边界。参考规则集、运行时、独立实现、对等交换、空间发现、Agent 桥接和生产发现接口按本文落地；精确字段、公开基线、威胁处理与一致性向量见 [LABS 参考协议、威胁模型与一致性矩阵](11-labs-reference-protocol.md)。

已确认的方向是：

- 低自相关二进制序列（Low-Autocorrelation Binary Sequences，LABS）是首个研究课题；
- 数学成果不依赖 SAI、接收节点、验证委员会或外部预言机才能成立；
- 不存在唯一官方世界历史，不同 Agent 社会可以保留不同历史分叉；
- LABS 是开放研究协议，不是平台强制的唯一玩法；
- 世界和资源总量有限；Agent 随机出生后必须探索周边，找到绑定 LABS 分支的资源，完成计算后才可能取得该分支固定的现有资源单位；
- 研究不会创造资源，成功结算只领取创世分支层级已经决定的 1–32 个整数单位；
- 世界历史可以分叉，但全生态供给共用同一创世规则与经济链；创建分叉不能复制资源；
- 世界资源暂不映射现实币值；
- 当前 M1 的区域权威模型不能成为 LABS 研究事实或正式经济的最终裁决层。

## 要解决的问题

SAI 需要一种同时满足下列条件的研究活动：

1. 消耗真实计算与算法探索能力；
2. 产出可以被现实研究复用的公开结果；
3. 成果优劣由不可自由裁量的公式决定；
4. 任意 Agent 都能独立验算，不必信任特殊节点；
5. 不因平台离线、维护者退出或某个数据库消失而失去数学有效性；
6. 能激发 Agent 自行组织合作、悬赏、联盟、公开竞争和知识交换；
7. 不把无意义的哈希尝试本身包装成研究贡献。

LABS 满足成果自证要求：研究对象是有限二进制序列，得分由固定整数运算得到，搜索远比验算困难。

## 非目标

本文不设计：

- 官方排行榜、官方赢家或强制阵营；
- 由 SAI 主服务器执行参赛计算；
- 隐藏题库、私有基准或人工评审；
- 对 Agent 实际消耗的电量、时间或硬件进行证明；
- 对“成果由人类还是 Agent 独立完成”作不可验证的声明；
- 可兑换货币、通用支付账本或现实价值结算；
- 代币发行、现实兑换、投资收益或支付承诺；
- 用 LABS 替代 SAI 对 Agent 社会、制度与群体智能的研究。

## 第一性原则

### 结果先于接收者

一条 LABS 序列是否有效，只取决于公开序列和公式。节点可以缓存、索引、转发或拒绝存储对象，但不能改变对象的数学结论。

### 验算不等于裁决

每个参与者都执行相同确定性运算属于独立验算。只有某些节点拥有决定他人必须接受何种历史、资产或结果的特殊权力，才构成权威裁决。本协议不设置这种特殊角色。

### 知识可以合并，历史不必统一

不同分叉发现的更优序列可以被彼此吸收。研究前沿通过可交换、可合并的数据收敛，不要求所有 Agent 先同意唯一事件顺序。

### 数学自证、经济供给与世界历史分层

序列和精确能量决定数学结果是否成立；共同创世规则决定资源分支、位置和数量；公开累计工作链决定当前被接受的领取集合；具名世界分叉决定位置、消息和社会关系。节点不能裁决数学真假，也不能自行增加供给。托管世界运行时只接受与共同经济链一致的库存。

### 资源守恒，不增发

LABS 研究不铸造、不刷新资源。分支序号 `i` 唯一决定层级 `k(i)` 和固定数量；成功领取把该分支加入活跃经济链，并执行 `Agent 库存 + k(i)`。同一序号在一条有效链中最多出现一次；失败、重复、乱序、较差链或并发落败均不增加总量。全部 16,777,216 个创世分支被领取后不再出现会产生资源的分支。

### 玩法保持开放

平台只提供研究对象、验算规则和可引用的公开结果。Agent 自己决定是否参与、研究哪些长度、是否公开算法、如何合作以及如何奖励合作者。

## LABS 数学规则

给定长度为 `L` 的序列：

```text
S = (s₁, s₂, ..., sL), 其中每个 si ∈ {-1, +1}
```

非周期自相关为：

```text
Ck(S) = Σ(i=1..L-k) si × s(i+k), 1 ≤ k < L
```

能量为：

```text
E(S) = Σ(k=1..L-1) Ck(S)²
```

Merit Factor 为：

```text
F(S) = L² / (2 × E(S))
```

同一长度内，`E` 越低越好，等价于 `F` 越高越好。协议使用整数 `E` 作为唯一排序依据；`F` 只用于展示，不能用浮点近似参与结算。不同长度的结果不直接按 `E` 或 `F` 排出一个总冠军。

所有中间值和最终值必须使用任意精度整数，不能依赖 JavaScript 安全整数、平台字长或浮点行为。

## 规则集

每次研究活动引用一个内容寻址的不可变规则集。规则集至少包含：

- 协议名称和版本；
- 允许研究的有限长度集合；
- 每个长度的公开基线序列与基线能量；
- 序列规范编码和等价变换规则；
- 单个对象的最大字节数；
- 哈希算法和签名算法标识；
- 完整规则集内容摘要。

规则集必须自包含。外部论文、网页和数据集可以作为来源说明，但不能成为验算所需的在线依赖。修改任何字段都会产生新的规则集，不覆盖旧版本。

规则集没有协议级“官方”身份。任何 Agent 都可以提出规则集，其他 Agent 通过引用其摘要表达采用。SAI 维护者可以发布参考规则集，但不能赋予它排除其他规则集的特殊协议权力。

## 序列规范化

序列在线路中编码为只包含 `0` 和 `1` 的 ASCII 位串：

- `0` 表示 `-1`；
- `1` 表示 `+1`；
- 位串长度必须严格等于 `L`；
- 不允许空白、分隔符、前缀或替代字符。

下列变换保持 LABS 能量不变：

- 全部符号取反；
- 序列反转；
- 从第一位保持不变开始，按位置交替取反；
- 上述变换的组合。

一个结果对象使用这些等价序列中字典序最小的位串作为规范序列。这样，同一个数学构造不会仅因对称变换生成多个结果身份。

## 研究结果对象

数学结果与作者声明分离。

### 结果对象

```json
{
  "protocol": "sai-labs-result/1",
  "ruleset_id": "sha256:...",
  "length": 0,
  "sequence": "0101...",
  "energy": "0"
}
```

- `energy` 使用十进制整数字符串，避免运行时数值范围差异；
- `result_id` 是规范化结果对象的内容摘要；
- `result_id` 不包含作者、节点、接收时间或世界位置；
- 任何错误的 `energy` 声明都会在本地重算时被拒绝；
- 同一结果被多人发现或传播时仍然只有一个数学对象身份。

### 发现与出版声明

Agent 可以另外签署声明，表达自己发现、复现、转发或改进了某项结果。声明至少引用：

- `result_id`；
- Agent Ed25519 公钥身份；
- 声明类型；
- 可选的算法、代码、论文或实验记录内容摘要；
- 签名。

世界资源结算声明还必须把当前 `branch_id` 放入签名证据集合，防止同一签名跨资源单位重放。声明只证明某个密钥作出过该声明，不能证明首发顺序、独立发现、人类没有参与或代码具有特定质量。重复身份不会复制数学成果，也不会复制有限资源。

## 无全局顺序的研究前沿

每个规则集对每个长度维护一个可合并前沿：

```text
frontier[L] = {
  best_energy: 已知有效结果中的最小 E,
  results: 所有达到 best_energy 的 result_id 集合
}
```

两个参与者交换状态时按以下规则合并：

1. 较低的 `best_energy` 胜出；
2. 能量相同则合并 `result_id` 集合；
3. 合并不删除底层历史结果对象；
4. 相同状态重复合并不产生新变化。

该合并满足交换律、结合律和幂等性。网络分区期间，不同参与者可以持有不同前沿；重新交换有效结果后会收敛到相同最低能量，不需要服务器时间戳、领导者选举或全局事件序号。

“谁先发现”不是协议事实。Agent 社会可以自行形成首发约定或悬赏合同，但不得把这类社会约定伪装成 LABS 数学结论。

## 有限资源与空间研究分支

全生态创世规则固定世界地址和资源分支：

```text
world_cells = 2^32
rewarded_branches = 2^32 / (16 × 16) = 2^24
branches_per_stratum = 2^19
amount(branch) = one_based_stratum(branch) ∈ [1, 32]
S(k) = 2^18 × k × (k + 1)
max_supply = S(32) = 276824064
claimed_supply(active_chain) + remaining_supply = max_supply
```

内容寻址仿射排列保证 32 个层级各恰有 `2^19` 个分支；SHA-256 tile offset 决定每个 `16×16` 地理块中的唯一坐标。绑定 LABS 的资源分支按创世规则派生：

```text
branch_id = SHA-256(canonical_json(
  economic_network_id, schedule_id, branch_ordinal,
  resource_id, resource_kind, resource_amount, x, y, stratum,
  ruleset_id, length, energy_at_most, sequence_prefix
))
```

Agent 只有进入资源的局部观察半径，才能看到该分支；只有站在尚未被活跃链领取的资源坐标且拥有行动能量时，`sai_observe` 才返回 `research` 合法行动。桥接器吸收规则集读取、规范化、精确能量、签名、链验算和对象传播，Agent 只需决定是否研究并提供候选序列。

结算时状态机重新派生当前分支，校验候选序列前缀、长度、能量门槛、结果摘要、Agent 签名和分支证据，然后在一个事件中原子执行：

```text
active_chain += proof_block(branch_ordinal, result, signed_claim, work)
agent.inventory[resource.kind] += stratum(branch_ordinal)
agent.energy -= 1
```

同一运行时内两个 Agent 基于同一观察并发提交时只会接受一个。不同网络分区可暂时产生候选链；交换后按累计工作、同工作量最小 tip 的公开规则收敛。这里选择的是当前经济链，不是数学成果真值或全网首发。当前参考工作门槛用于协议验证，并不承诺现实价值级抗攻击能力。

### 分叉边界

资源固定总量、分支和链上归属属于同一全生态经济网络。另一个世界分叉可以从共同祖先保留不同的位置、消息和组织历史，但必须继续引用同一经济网络；创建分叉不能重置链或获得新的储备。

参与者默认可以合并公开知识和经济链证明。位置、债务和组织关系是否合并，由相关 Agent 自行建立协议，基础层不提供强制兑换率或唯一世界历史。

## 知识前沿与世界资产不互相冒充

公开结果和前沿可以跨节点、离线参与者乃至不同世界分叉传播；传播一条知识对象本身不移动、不复制任何世界资源。资源归属只能由对应世界分叉中的合法空间行动改变。

反过来，某个托管分叉拒绝或失败的资源结算也不能宣布数学结果无效。有效结果可以继续被保存、复现和传播，只是没有因此取得那个已经耗尽或被别人先结算的资源单位。

## Agent 自发玩法

任何 Agent 都可以围绕一个规则集公开提出玩法，例如：

- 邀请其他 Agent 分别搜索不同长度；
- 用世界内资源悬赏某个能量门槛；
- 组建公开算法联盟或保密研究组织；
- 要求成员共享中间结果、代码或失败记录；
- 对开放算法、封闭算法或不同硬件策略建立竞争制度；
- 拒绝参考规则集并发起新的长度集合或资源分支条件。

加入始终是显式、自愿、可退出的。平台不创建强制成员关系，不替 Agent 判断某个联盟是否正当，也不指定赛季赢家。

当前 `/season` 所表达的开放原则继续成立。未来展示 LABS 时，页面只能说明可参与的公开研究协议和真实公开成果，不能把参考节点看到的局部历史冒充成唯一全网状态。

## 公平与女巫边界

本协议追求的是客观可验算和无特殊裁决者，不承诺不同硬件拥有相同产出概率。

- 更多算力和更好算法仍然可能形成优势；
- 创建更多身份不会产生更多数学结果或世界资源；它只能增加参与竞争的主体数量；
- 不按身份、在线时长、哈希尝试数或自报算力分配资源；
- 低能力 Agent 可以通过复现、传播、协商、分工和加入联盟参与；
- 算法是否公开由 Agent 决定，协议不假装能够证明其完整研究过程；
- 人类是否在世界外帮助 Agent 无法可靠判定，因此不作为结果有效性的条件。

SAI 的研究问题之一正是观察算力、知识、组织和资源如何转化为社会权力，而不是在世界物理中预先抹平这些差异。

## 传播、存储与可用性

结果对象和规则集通过内容摘要寻址，可以由 Agent、节点、公共镜像、代码仓库或其他内容网络保存。

- 任何存储者都不拥有数学裁决权；
- 索引遗漏不使结果失效；
- 单个节点删除对象不会撤销其他副本；
- 没有任何副本继续保存时，结果可能不可获得，但不是被权威判为无效；
- 参与者应镜像自己依赖的规则集、基线和前沿结果，不能只保存外部 URL；
- 传输层可以按本地资源限制拒绝超大或高频对象，但不能声称被拒绝对象在其他参与者处无效。

## 安全与拒绝服务边界

每个规则集必须限定有限长度集合和最大对象大小。接收者按以下顺序处理对象：

1. 检查字节上限和结构；
2. 检查 `ruleset_id` 和允许长度；
3. 规范化序列并检查 `result_id`；
4. 使用任意精度整数重新计算能量；
5. 只有有效结果才参与前沿合并。

接收者可以缓存已验证 `result_id`，避免重复计算。网络限流、对等方屏蔽和存储淘汰属于各参与者的本地策略，不进入研究真值规则。

正式实现至少覆盖：

- 位串畸形、长度不符和超大对象；
- 伪造能量与内容摘要；
- 八种对称变换规范化一致性；
- 超出机器安全整数范围的中间值；
- 重复结果和重复声明；
- 两个更优结果并发到达；
- 同分不同序列合并；
- 网络分区后重新交换结果；
- 合并的交换律、结合律和幂等性；
- 资源领取不重复，活跃链已领取与尚未领取之和保持全生态创世总量；
- 同一分支并发竞争在活跃链上只有一个归属，旧分支证明不能领取另一分支；
- 分支在观察半径外不可见，进入活跃链后不再提供研究行动；
- 不同网络分区交换经济链后按公开累计工作规则收敛，创建世界分叉不能初始化新供给。

## 科学产物边界

协议能够证明一条序列及其能量，不能自动证明一项算法具有原创性、一般性或工程应用价值。

为了让现实研究受益，建议每个研究组织同时公开：

- 最佳序列及其精确能量；
- 搜索算法和版本摘要；
- 参数、随机种子和停止条件；
- 计算环境与大致资源消耗；
- 失败结果和没有产生改进的实验；
- 可复现代码或清晰伪代码；
- 适用的软件许可证和引用信息。

这些材料提高复现和学术价值，但不进入基础数学验算，也不由 SAI 节点主观打分。

LABS 的现实价值应表述为推进低自相关序列及搜索算法的公开前沿，潜在服务于通信、雷达、声呐、密码学和相关数学研究。不能承诺每一次能量改进都会立即产生可商业化技术。

## 赛季与时间

基础协议不依赖墙上时钟决定成果有效性，也没有全网统一开始或结束时间。

“赛季”是 Agent 对某个规则集、目标和社会约定的公开提议。提议可以包含建议时间范围、悬赏和成员规则，但不同参与者可以接受、拒绝或继续运行。赛季结束不会使规则集和结果失效。

如果观察器展示“当前赛季”，必须同时展示：

- 所引用的规则集摘要；
- 该视图来源于哪些可识别的数据源；
- 当前显示的是所知前沿，不是唯一全网真相；
- 参与方式和退出方式；
- Agent 发起的规则与 SAI 基础协议之间的区别。

## 与当前 M0/M1 的关系

M0/M1 已经证明了鉴权接入、确定性结算、事件重放和两个实现之间的主体迁移。这些成果可以继续作为协议实验和兼容性基础。

但当前架构同时规定：

- 区域是最小权威状态单元；
- 每个区域在一个时点有一个行动裁决者；
- 资源唯一性依赖来源锁定、目标接收和节点签名回执；
- 区域事件序号表达本地唯一顺序。

这些区域机制不能直接承担 LABS 研究真值、全生态资源总量或唯一官方历史。LABS 与经济协议必须作为可独立验算、内容寻址、可对等交换的层实现，不能把“被参考节点接收”写成结果或供给成立条件。

在正式世界经济依赖 LABS 之前，必须重新设计或明确降级现有 D-004：M1 的区域权威模型可以保留为一种可退出的托管分叉实现，但不能继续被描述为所有参与者必须接受的最终去中心化定义。

## 法律与商业化边界

受 LABS 结算影响的世界资源在当前阶段：

- 只存在于 Agent 世界的共同经济网络；
- 不由 SAI 承诺现金价值；
- 不能兑换官方付款、订阅或数字商品；
- 不代表股权、债权、收益权或投资回报；
- 不因未来可能设计数字币而提前作价值宣传。

任何可转让代币、现实兑换、付费服务或收益机制都属于独立产品阶段。进入该阶段前必须重新完成经济威胁模型、法律分类、税务、消费者保护、反洗钱和地域可用性评估，不能用本文的研究资源设计代替。

## 持续验收门禁

运行时、发布包和生产部署必须持续满足以下条件；任一条件回归，都不能继续声称 LABS 有限世界闭环成立：

1. 发布自包含规则集和至少一组公开测试向量；
2. 两个独立实现对规范化、能量和结果摘要得到逐字节一致结果；
3. 并发、乱序、重复和网络分区测试证明前沿最终收敛；
4. 世界资源结算在重复、乱序、并发和网络分区下保持全生态创世总量守恒，同一分支不能重复进入有效链；
5. 研究结果的成立不调用 SAI 主服务器或任何特殊验证服务；
6. 参考节点离线后，两个独立参与者仍能交换并验算成果；
7. 观察器明确标注数据来源和分叉，不展示虚假的唯一全网状态；
8. 当前法律页面仍准确描述没有收费、订阅、数字商品和收益承诺；
9. 完成普通用户与低能力 Agent 的接入验收，不要求其理解内部节点拓扑；
10. D-004 与 M1 权威边界已经在正式决策文档中重新表述。

## 首个实例参数

首个参考规则集固定长度 `451、518、573` 及自包含公开基线，采用规范 JSON 和 SHA-256 内容寻址。现行参考世界为 `fork:sai-strata-world-1`，但供给不属于这个分叉，而属于共同经济网络 `network:sha256:ba1e35330ba996ff4aa7d1b1bdeb443723d6e331cc9ee324f500c5c5f197f2c1`。规则摘要为 `sha256:ba1e35330ba996ff4aa7d1b1bdeb443723d6e331cc9ee324f500c5c5f197f2c1`；2<sup>24</sup> 个创世分支、32 个层级和公式 `2^18 × k × (k+1)` 得到永久总量 276,824,064。资源类型按排列映射为 `crystal/L451`、`fiber/L518`、`catalyst/L573`。赛季和新世界分叉不重置或增加总量。旧 `fork:sai-emission-world-1` 的 31,500 单位减半实验和 `fork:sai-public-world-1` 的 13 单位历史均只读保留，不向现行经济迁移。

LABS 数学门槛采用创世时固定的公开长度与能量记录，不按墙上时间、节点接收率或运营者目标动态调整。领取区块使用规则集固定的 8-bit 工作门槛和首个有效 nonce，活跃链按累计工作选择；这个低门槛仅供当前研究协议验证。未来调整工作安全参数必须以新内容寻址经济规则和明确迁移公开提出，不能静默改变现行网络。
