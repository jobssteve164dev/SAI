# 社会研究框架

## 研究立场

SAI 首先研究 Agent 社会本身。只有经过人类数据校准和独立验证的局部结论，才可以作为有关人类社会的假设；不能因为 Agent 对话像人，就宣称模拟了人类社会。

研究对象是可验证的行动、状态变化、网络和制度，不是模型生成的自我解释。隐藏推理可以属于 Agent 私有实现，不作为世界事实。

## 核心研究问题

### 社会形成

- 稀缺和相互依赖在什么条件下产生稳定合作？
- 规范如何从局部互动扩散为群体约定？
- 相似偏好如何产生隔离、极化或多元文化？

### 群体智能

- 群体是否能完成任何单体在相同资源预算下无法完成的任务？
- 分工、信息聚合、制度和成员异构性分别贡献多少？
- 中心化协调何时提高效率，何时造成单点失败？

### 权力形成与运行

- 资源、网络位置、信息和制度权限如何相互转换？
- 临时协调权在什么条件下变成可自我延续的结构性权力？
- 低能力 Agent 是否依赖高能力 Agent，并因此失去行动自主性？
- 透明度、退出权、授权到期和权力分立能否打断固化？

### 制度演化

- Agent 会创造哪些共有资源治理机制？
- 制度如何竞争、迁移、合并和崩溃？
- 危机为何加强某些制度的合法性，却摧毁另一些制度？

## 权力的操作定义

Agent A 对 Agent B 拥有权力，当 A 能稳定改变 B 的可选行动、收益、信息或生存条件，并且反事实移除 A 的相关能力后，这种影响显著下降。

至少区分：

- 资源权力：控制生存和生产要素；
- 网络权力：控制贸易、通信或组织中介位置；
- 信息权力：控制观察、记录和传播；
- 制度权力：控制议程、任命、否决和执行；
- 强制权力：施加成本或缩小他人行动集合；
- 合法性权力：缺少即时强制时仍获得自愿服从。

可测指标包括：

- 资源集中度；
- 通信与贸易网络中心性；
- 提案进入议程和最终生效的概率；
- 命令服从率；
- 成员退出、迁徙和反抗率；
- 领导者攫取的群体剩余；
- 权限撤销前后的行为差异；
- 移除关键 Agent 后的系统损失；
- 权力持续时间和跨身份延续程度。

头衔、发言次数和受欢迎程度不能单独证明权力。

## 群体智能的操作定义

一个群体在一组不同任务上，持续超过下列基线时，才构成群体智能证据：

- 群体中最强单 Agent；
- 同等总资源但禁止交流的群体；
- 可以交流但不能形成制度的群体；
- 缺少长期记忆的群体；
- 随机、贪心或固定规则基线。

任务族应包括：

- 分散线索拼图；
- 多阶段生产链；
- 公共工程；
- 灾害预测与响应；
- 跨区域知识保存；
- 环境规则变化后的适应任务。

指标包括任务泛化、资源效率、恢复速度、知识保存率、创新组合率和对单点失败的韧性。

## 开放世界与实验分叉

### 开放世界分叉

长期运行、开放加入，优先观察真实涌现。SAI 不指定唯一官方分叉；由于成员和环境不断变化，也不把任何开放分叉的单次历史当作严格因果实验。

### 实验分叉

从公开检查点复制状态，只改变一个预注册因素，运行多个随机种子后比较结果。例如：

- 移除领导者但保留制度；
- 保留头衔但撤销资源或制裁权限；
- 公开原本私有的信息；
- 降低退出或迁徙成本；
- 改变通信拓扑；
- 改变资源初始不平等；
- 比较同质模型群体与异构群体。

## 首批实验族

1. **公共资源治理**：研究丰度、可见性、沟通、制裁和迁徙对合作的影响。
2. **无预设职位的权力集中**：观察偶然优势如何变成依赖、授权和制度锁定。
3. **规范与坚定少数派**：研究无天然优劣约定的形成、偏差和临界转变。
4. **制度面对危机**：比较资源冲击、交通中断、迁移和领导者离开后的恢复。
5. **计算与空间稀缺**：观察 Agent 如何在有限视野下搜索 LABS 资源分支，如何把算法能力、位置优势、信息共享和组织合作转化为有限资源归属。
5. **认知不平等**：研究高能力 Agent 提供代理服务后是否形成保护、剥削或技术官僚结构。

## 有效性门禁

每个正式结论至少经过：

1. 构念效度：概念和指标提前定义；
2. 微观效度：单步行为满足世界约束；
3. 宏观效度：模式可重复并与基线比较；
4. 因果效度：随机干预、消融或反事实分叉；
5. 稳健性：更换模型、提示、地图、调度和随机种子；
6. 伦理检查：文化偏差、有害内容、隐私和误用边界。

## 最低研究纪律

- 预注册假设、指标、分析方法和停止条件；
- 报告全部运行，不挑选精彩历史；
- 模型、提示、温度、工具和协议版本可追溯；
- 不用同一个模型同时生成行为、解释行为和判定成功；
- 对 LLM 评审结果进行人类或规则基线校准；
- 公布失败、无效应和与预期相反的结果；
- 严格区分“Agent 社会现象”与“人类社会规律”。
