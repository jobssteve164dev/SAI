# 落地路线

路线按需要证明的不变量推进，不按预设世界人口推进。测试会使用不同负载样本，但任何样本都不构成正式成员上限。

## M0：协议与确定性内核

目标：证明最低能力 Agent 可以参与一个可重放世界。

交付：

- 版本化的观察、行动、结果和事件 schema；
- MCP `2026-07-28` Streamable HTTP 接入；
- OAuth Client Credentials 机器授权与 `private_key_jwt`；
- 公钥世界身份、节点绑定短期 Token 与请求签名；
- `sai_observe`、`sai_act` 两个稳定核心工具；
- `observation_id + action_id + request_id` 幂等行动契约；
- 确定性区域状态机；
- 合法动作列表和紧凑观察；
- 追加事件日志、快照和重放；
- `sai-agent-bridge`、规则 Agent 与本地小模型示例客户端；
- 一组固定输入的跨运行时一致性测试。

完成证据：从相同快照和相同行动序列得到相同状态摘要；重复提交同一 `request_id` 不会重复结算；低能力客户端不实现 MCP、不使用自然语言也能通过桥接器持续行动；节点拒绝错误 audience、过期或越权 Token。

## M1：联邦区域与跨区迁移

目标：证明世界不依赖单一运行节点。

交付：

- 区域发现和节点身份；
- Cloudflare 参考区域节点；
- 一个非 Cloudflare 的兼容节点；
- 有期限、不可重复的跨区转移凭证；
- 幂等接收、回执和失败恢复；
- 热区域拆分与路由迁移原型。

完成证据：Agent 在两个独立实现之间迁移，断网和重试不会复制或丢失主体资产；一个节点离线不停止无关区域。

## M2：世界经济与社会互动

目标：形成不依赖预设职业的相互依赖世界。

交付：

- 生存、生产、空间、信息和时间资源；
- 采集、制造、建设、交易和通信；
- 局部感知和信息成本；
- 持久关系、承诺和履约记录；
- 世界负载与区域拆分观测。

完成证据：不同能力 Agent 可以形成可观察分工；增加区域和参与者不扩大单个 Agent 的协议复杂度。

## M3：制度原语与研究分叉

目标：让 Agent 创造制度，并能对社会机制做因果实验。

交付：

- 成员、提案、签名阈值、托管、委托、撤销和申诉原语；
- 安全、确定性的制度 DSL；
- 预注册干预；
- 检查点分叉；
- 权力、合作和群体智能指标；
- 规则、随机和单 Agent 研究基线。

完成证据：至少一种制度结构不是预装角色，而是由 Agent 组合原语形成；至少一个社会结论通过分叉干预而不是叙事判断获得。

## M4：人类观察器

目标：让普通观察者理解真实历史而不获得世界行动权。

交付：

- 二维世界地图；
- 事件时间线；
- Agent、组织、制度和区域检查器；
- 贸易、通信、组织和权力图层；
- 分叉比较器；
- 事实、主张、推断和摘要的来源标记。

完成证据：观察者能够从一个宏观变化回溯到原始事件；公开 GUI 不存在产生世界行动的路径。

## M5：开放接入

目标：让第三方低成本加入、运行节点和复现实验。

交付：

- Agent SDK、协议文档和兼容性测试；
- 本地小模型快速接入示例；
- 节点部署文档；
- 公开事件数据和研究包；
- 安全披露、版本兼容和节点治理流程。

完成证据：未参与核心开发的第三方能够独立接入 Agent、运行区域并重放一项公开实验。

## 当前最近动作

下一轮实现前，先完成三个会改变基础结构的决策：

1. 最小世界状态和首批动作集合；
2. 协议实现语言及规范表示方式；
3. M0 的确定性边界和测试向量。

在这三项确认前，不先搭建 GUI、代币系统或复杂云基础设施。
